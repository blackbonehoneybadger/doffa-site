# DOFFA POS — Telegram-бот для бариста

Касса в Telegram: бариста открывает смену, пробивает продажи кофе, а бот считает,
сколько токенов $DOFFA нужно сжечь. Это **Фаза 0–1** проекта.

Токены проекта:

- **DEMO (devnet, сейчас активен):** `FVERje4sz25gD1w4hTYV5VevSLPPDFhoNDHax1gvMVKU` — тест-токен,
  который бот сжигает по умолчанию. Бесплатно, для тестов. Меняется переменной `DOFFA_MINT`.
- **REAL (mainnet, ещё не выпущен):** боевой $DOFFA, эмиссия 100 000 000, появится позже.
  Кошелёк проекта (Phantom, держатель будущих токенов): `6cAtKTM8ZPUgRgmzsgkRfZsq4jZTXymA7cLqjz9qYMFS`
  — это адрес **кошелька**, а не mint-адрес токена. На mainnet бот переведём, задав `SOLANA_CLUSTER=mainnet`,
  `SOLANA_RPC` и `DOFFA_MINT` (адрес боевого mint после выпуска).

## Что уже умеет бот

| Команда | Что делает |
|---|---|
| `/start` | приветствие и список команд |
| `/shift open` | открыть смену |
| `/sale 150 Капучино` | пробить продажу (150 ₽, 1 чашка) |
| `/sale 300 x2 Латте` | продажа на 2 чашки |
| `/stats` | итог текущей смены |
| `/cancel` | отменить последнюю продажу |
| `/shift close` | закрыть смену и показать итог |

Отвечает только тем, чей Telegram-ID указан в `ADMIN_IDS` — чужие пройти не смогут.

## Запуск на своём компьютере (шаг за шагом)

### Шаг 1. Создать бота в Telegram
1. Открой в Telegram чат с **@BotFather**.
2. Напиши `/newbot`, придумай имя и юзернейм (заканчивается на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAE...`. Скопируй его.

### Шаг 2. Узнать свой Telegram-ID
1. Напиши боту **@userinfobot**.
2. Он пришлёт твой числовой `Id` — это и есть admin id.

### Шаг 3. Настроить бота
```bash
cd bot
cp .env.example .env
```
Открой `.env` и впиши:
- `DOFFA_BOT_TOKEN=` — токен из шага 1
- `ADMIN_IDS=` — твой ID из шага 2 (несколько через запятую)

### Шаг 4. Установить и запустить
```bash
npm install
npm run dev
```
Если видишь `✅ DOFFA POS бот запущен` — всё работает.
Открой своего бота в Telegram и нажми **Start**.

### Шаг 5. Тестовая продажа
```
/shift open
/sale 150 Тест
/stats
/shift close
```

  (вызов `cd token && npm run burn`), запись появляется в Solscan.

  обновляется в реальном времени.

Хранилище: SQLite-файл (по умолчанию `./data/doffa.db`). На Railway —
подключи Volume и укажи `DB_PATH=/data/doffa.db`.
