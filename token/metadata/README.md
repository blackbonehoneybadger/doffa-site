# Метаданные токена DOFFA

Здесь лежат файлы, которые кошельки и explorer'ы показывают как имя и логотип
токена. Загружает их **владелец** — ключ от пиннинг-сервиса является секретом
и в репозиторий не попадает.

## Файлы

| Файл | Что это |
|---|---|
| `logo-source.jpeg` | исходник от владельца, 704×531 — **не для загрузки** |
| `logo-512.png` | квадрат 512×512, 60 КБ — **основной, его и загружаем** |
| `logo-256.png` | квадрат 256×256, 19 КБ — запасной для лёгких клиентов |
| `doffa.json` | шаблон метаданных, требует подстановки ссылки |

Логотип обрезан по кругу бейджа: фотофон с зёрнами и бликами отброшен, потому
что в списке кошелька иконка показывается размером 32×32, и фон там превратился
бы в грязь. В таком размере мелкий текст «Espresso Bar / Since 2021» всё равно
не прочитается — узнаваемость держится на силуэте чашки с ногами.

## Почему нельзя временную ссылку

`METADATA_URI` записывается в блокчейн один раз. После отзыва authority
переписать его **невозможно**. Если хостинг исчезнет — токен навсегда останется
без имени и логотипа, и исправить это будет нельзя.

Поэтому Vercel, Netlify, ngrok, свой VPS и любые «пока полежит тут» не годятся.
Только контент-адресуемое постоянное хранилище: **IPFS** или **Arweave**.

Скрипт `token:metadata` проверяет URI на признаки временного хостинга и
отказывается работать, если находит их.

## Порядок загрузки

Два шага, порядок важен: сначала картинка, потом JSON со ссылкой на неё.

### 1. Загрузить `logo-512.png`

Любой из вариантов:

- **Pinata** (https://pinata.cloud) — бесплатный тариф, удобный интерфейс;
- **NFT.Storage** (https://nft.storage) — бесплатно, IPFS + Filecoin;
- **Irys / Arweave** (https://irys.xyz) — платно и навсегда, без риска unpin.

Получишь ссылку вида:

```
https://gateway.pinata.cloud/ipfs/bafybe...
ipfs://bafybe...
https://arweave.net/xxxxxxxx
```

### 2. Подставить ссылку в `doffa.json`

Замени **оба** вхождения `REPLACE_WITH_PERMANENT_LOGO_URL` — в поле `image`
и внутри `properties.files[0].uri`.

Проверить, что JSON остался валидным:

```bash
node -e "const j=require('./token/metadata/doffa.json');
if(JSON.stringify(j).includes('REPLACE_WITH')) throw new Error('ссылка не подставлена');
console.log('JSON валиден, image:', j.image)"
```

### 3. Загрузить `doffa.json` туда же

Полученную ссылку **на JSON** (не на картинку) записать в `token/.env`:

```
DOFFA_METADATA_URI=https://gateway.pinata.cloud/ipfs/bafy...
```

### 4. Проверить перед mainnet

```bash
cd token && npm run token:check-wallet
```

Скрипт скажет, принял ли он URI. Дополнительно открой ссылку в браузере и
убедись, что:

- JSON отдаётся и читается;
- поле `image` открывается и показывает логотип;
- `name` = `DOFFA`, `symbol` = `DOFFA`;
- ссылка не требует авторизации и работает в режиме инкогнито.

Последний пункт важен: если файл виден только тебе, кошельки покажут пустоту.
