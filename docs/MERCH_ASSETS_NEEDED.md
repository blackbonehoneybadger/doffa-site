# Мерч — какие финальные материалы нужны

Страница `/merch` собрана без фейковых фото: категории и коллекция DOFFA показаны
с аккуратными заглушками и честными статусами. Ниже — список реальных материалов,
которые нужно доснять/предоставить, чтобы заменить заглушки.

Пока фото нет — **не подставлять сгенерированные или чужие изображения**. Заглушка
честнее фейка.

## Коллекция DOFFA

У каждой позиции в `app/config/merch.ts` есть честный статус
(`concept` / `coming` / `preorder` / `live`). Обновлять статус на `live` и
добавлять фото **только когда изделие реально производится**.

## Что подключить к странице по мере готовности

| Что | Как |
|---|---|
| Фото категорий/коллекции | положить в `public/brand/merch/…` и проставить путь в `image` соответствующей категории в `app/config/merch.ts` (сейчас `null` → заглушка) |
| Онлайн-приём заявок (форма → БД) | env `NEXT_PUBLIC_MERCH_ORDERS_ENABLED=true` + прогнать `npm run migrate` (добавит `merch_orders`, `merch_order_attempts`) |
| Отдельный канал связи по мерчу | env `NEXT_PUBLIC_MERCH_CONTACT_URL`, `NEXT_PUBLIC_MERCH_CONTACT_LABEL` (по умолчанию — реальный WhatsApp кофейни) |
| Адрес шоурума | env `NEXT_PUBLIC_MERCH_SHOWROOM_ADDRESS` |
| Загрузка файлов в форме (логотип/эскиз) | **Planned** — сейчас клиент прикладывает референс через WhatsApp; когда понадобится, подключить Vercel Blob client-upload по образцу `/api/admin/upload-token` |

## Переменные окружения (мерч)

```
NEXT_PUBLIC_MERCH_ORDERS_ENABLED=      # true → форма пишет заявки в БД; иначе honest WhatsApp-фолбэк
NEXT_PUBLIC_MERCH_CONTACT_URL=         # опционально; по умолчанию WhatsApp кофейни
NEXT_PUBLIC_MERCH_CONTACT_LABEL=       # опционально; по умолчанию «WhatsApp»
NEXT_PUBLIC_MERCH_SHOWROOM_ADDRESS=    # опционально
```

Приватные ключи и серверные токены в `NEXT_PUBLIC_*` **не хранить**.

## Куда поступают заявки

- **Онлайн-приём выключен (по умолчанию):** форма собирает данные и открывает
  чат в WhatsApp кофейни с уже готовым текстом заявки. Фальшивого «успешно
  отправлено» нет — пока пользователь не отправит сообщение, заявки нет.
- **Онлайн-приём включён** (`NEXT_PUBLIC_MERCH_ORDERS_ENABLED=true` + миграция):
  `POST /api/merch/order` валидирует (zod), проверяет honeypot и rate-limit по IP
  (5/час), и пишет заявку в таблицу `merch_orders`. Персональные данные наружу
  не отдаются.

## Чего НЕ делаем

- не выдумываем цены (везде «рассчитывается индивидуально»);
- не выдумываем товары в наличии (статусы честные);
- не добавляем фейковые отзывы покупателей;
- не имитируем успешную отправку формы без реального канала.
