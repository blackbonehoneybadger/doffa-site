# Внешние API на сайте

Дата: 2026-07-27

Из каталога [public-apis](https://github.com/public-apis/public-apis) к doffa.coffee
подключены три сервиса — те, что реально что-то дают сайту кофейни. Все три
бесплатные и вызываются **только с сервера**.

| Что | Источник | Ключ | Кэш | Где видно |
|---|---|---|---|---|
| Погода в ауле | [Open-Meteo](https://open-meteo.com) | не нужен | 15 мин | плашка рядом с адресом на главной |
| Курсы валют | [open.er-api.com](https://open.er-api.com) | не нужен | 6 ч | «≈ $X» под ценой товара в `/merch` |
| Котировки SOL и $DOFFA | [Jupiter](https://dev.jup.ag) | необязателен | 5 мин | блок «Рыночная цена» на `/transparency` |

## Общее правило

Ни одна из интеграций не является обязательной. Если источник недоступен,
отвечает мусором или переменные не заданы — элемент **просто не показывается**.
Заглушек, прочерков и «примерных» чисел нет нигде: выдуманная цена или чужая
погода хуже, чем их отсутствие.

Весь разбор ответов терпим к смене формата у поставщика (принимаются оба
известных варианта полей), а любая ошибка сети превращается в `null`, а не в
исключение — страница не падает.

## Переменные окружения

Все — **серверные**, без префикса `NEXT_PUBLIC_`. В браузерный bundle не попадают.

```
# Погода. Без координат плашка не показывается — значения по умолчанию
# намеренно отсутствуют, чтобы не показать погоду не того места.
WEATHER_LATITUDE=
WEATHER_LONGITUDE=

# Курсы валют. Включены по умолчанию, ключ не нужен.
FX_RATES_ENABLED=true
FX_BASE_CURRENCY=RUB

# Котировки. Включены по умолчанию; ключ нужен только если перейдём
# на платного поставщика (переменная общая с маркетплейсом).
TOKEN_PRICE_ENABLED=true
DOFFA_PRICE_PROVIDER_API_KEY=
```

### Что нужно сделать владельцу

Задать в Vercel `WEATHER_LATITUDE` и `WEATHER_LONGITUDE` — координаты кофейни
(ул. Калмыкова, 10, аул Псаучье-Дахе). Взять их можно так: открыть точку в
Яндекс/Google Картах, нажать на неё правой кнопкой → координаты, и вставить два
числа. До этого момента блок погоды на сайте отсутствует.

Остальные две интеграции работают без настройки.

## Про цену $DOFFA

У токена **нет рыночной цены**, пока не создан пул ликвидности на DEX
(`ECOSYSTEM.status.dex` — «Готовится»). Это нормальное состояние, а не сбой:
источник просто не вернёт котировку по этому mint.

Страница `/transparency` в этом случае пишет об этом прямым текстом и
показывает для ориентира цену SOL. Как только пул появится — котировка
подтянется автоматически, править код не нужно.

## Почему не «все 1400 API»

`public-apis` — это README со ссылками, а не библиотека: устанавливать там
нечего. Каждая строка каталога — отдельный чужой сервис со своей регистрацией,
своим ключом и своим форматом ответа. Для сайта кофейни осмысленны три штуки
выше; остальные (медицина, спорт, ML, госреестры) к делу отношения не имеют, а
каждая лишняя интеграция — это ещё одна точка отказа и ещё один секрет,
который надо хранить.
