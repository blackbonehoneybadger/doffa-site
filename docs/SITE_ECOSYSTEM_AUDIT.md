и убрать все старые термины/механики и любые обещания дохода.

по мере прохождения фаз.

## Область поиска

Аудит проведён по **живому сайту** — каталог `app/`, `public/`, корневой `README.md`,
`app/layout.tsx` (metadata/OG/Twitter). Намеренно **исключены** из живого сайта:

- `.claude/skills/**` — данные дизайн-скиллов (CSV/справочники), не рендерятся на сайте;
- `token/**` — одноразовые скрипты выпуска токена (запуск локально), включая `04-burn.ts`;
- `plan/**` — внутренние планы проекта.

Совпадения слов вроде `caps`/`burn`/`profit` в этих каталогах — ложные (данные скиллов,
имена переменных, планы), к публичному сайту отношения не имеют.

### Централизованная конфигурация

Добавлен `app/config/ecosystem.ts` — единый источник правды: mint токена, размер и адрес
Reward Vault, ссылки на игру/APK/DEX/Solscan, **статусы функций** (`live`/`testing`/`planned`/`paused`)
и рекламный флаг. Читает `NEXT_PUBLIC_*`, приватные ключи не хранит. Путь адаптирован под
существующую архитектуру (`app/`, а не `src/`).

## Переменные окружения (NEXT_PUBLIC_*)

Читаются в `app/config/ecosystem.ts`. Обязателен только mint (есть дефолт):

```
NEXT_PUBLIC_DOFFA_MINT=57aAfCuXx7uuc8g8P9kTxR65TKQtZsFDJeKhdD5xu6uo
NEXT_PUBLIC_REWARD_VAULT_ADDRESS=      # пусто → Reward Vault показывается как Planned
NEXT_PUBLIC_REWARD_POOL_INITIAL=1000000
NEXT_PUBLIC_GAME_WEB_URL=              # пусто → кнопка игры неактивна
NEXT_PUBLIC_ANDROID_APK_URL=           # пусто → «Android-версия готовится»
NEXT_PUBLIC_ANDROID_VERSION=
NEXT_PUBLIC_ANDROID_SIZE=
NEXT_PUBLIC_ANDROID_SHA256=
NEXT_PUBLIC_DEX_URL=                   # пусто → «Пул пока не запущен»
NEXT_PUBLIC_SOLSCAN_TOKEN_URL=
NEXT_PUBLIC_CLAIMS_STATUS=testing
NEXT_PUBLIC_DEX_STATUS=planned
NEXT_PUBLIC_BURN_STATUS=planned
NEXT_PUBLIC_ADS_ENABLED=false
```

Приватные ключи в `NEXT_PUBLIC_*` хранить **запрещено**.
