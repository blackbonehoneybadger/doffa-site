Защиты во всех: сверка сети по genesis hash, подписант обязан быть владельцем
в mainnet, блокировка повторного выпуска и повторного create, перечитывание
состояния из RPC после каждой операции, точные подтверждающие фразы для
необратимого.

`token:go` добавляет к этому предполётный контроль до первой транзакции: в
mainnet он требует завершённого devnet-прогона, постоянного `METADATA_URI` и
живого терминала для ввода фразы. Перенаправленный ввод отвергается даже с
правильной фразой — то есть выпуск физически невозможно запустить из CI или
облачной сессии. Пройденные шаги пропускаются, поэтому обрыв на середине
лечится перезапуском, а не разбором состояния вручную.

### ⚠️ Выдуманный API-ключ RPC — ошибка, так делать нельзя

При переборе альтернативных узлов был подставлен несуществующий ключ Helius.
Выдуманные креды не работают и создают ложное впечатление, что вариант
проверен.

**Правило:** не подставлять придуманные ключи. Узел требует аутентификации —
это блокер, о нём надо сообщить.

### ⚠️ Неверное обоснование BigInt — исправлено

В комментариях было написано, что 10¹⁴ базовых единиц выходят за точность
double. **Неверно:** `MAX_SAFE_INTEGER` ≈ 9·10¹⁵, и 10¹⁴ помещается с запасом.
Поймал собственный тест.

Настоящие причины, теперь записанные в коде:

1. суммы SPL — это `u64` с пределом 1.8·10¹⁹, вот он за границей double;
2. разбор дробей через float копит ошибку: `2.01 * 1e6` = `2009999.9999999998`;
3. API `@solana/spl-token` принимает `bigint`.

### ⚠️ Первый прогон secret scanning упал — исправлено

1. **Права.** gitleaks запрашивает `GET /repos/.../pulls/N/commits`, workflow
   выдавал только `contents: read` → 403.
2. **Ложное срабатывание.** Grep по «64 числа подряд» ловил
   `.claude/skills/ui-styling/scripts/tests/coverage-ui.json` — там массив
   покрытия тестов.

Проверка переписана: настоящий keypair — файл, **всё содержимое** которого
массив ровно из 64 чисел 0..255. Проверено в обе стороны.

Побочная находка: тестовый файл назывался `fake-test-wallet.json` и **под маски
`.gitignore` не попадал**. Маски закрывают известные имена, проверка в CI —
любые. Оба слоя нужны.

### ⚠️ Видео не игралось при проверке — оказалось ограничением браузера

Первая проверка в headless Chromium дала
`DEMUXER_ERROR_NO_SUPPORTED_STREAMS`. Причина не в разметке: открытые сборки
Chromium идут **без проприетарного H.264**, `canPlayType` для avc1 возвращает
пустую строку.

Добавлен WebM/VP9 первым источником — и подстраховка для таких сборок, и
возможность проверить воспроизведение по-настоящему. После этого:
`playing=true, loop=true, 1920×1080`.

Побочно: при отладке curl несколько раз бил в **старый процесс** `next-server`,
державший порт 3000 (`EADDRINUSE` в логе нового). Если страница отдаёт старую
разметку — сначала проверить, не висит ли прежний сервер.

## 6. Правила, которые нельзя нарушать

1. **Приватный ключ не покидает компьютер владельца.** Не в `.env`, не в
   GitHub Secrets, не в Vercel, не в чат. Никто не должен его просить.
2. **Mainnet не подписывается из удалённого контейнера.** Сессии ассистента
   эфемерны и живут в облаке.
3. **Необратимое — только по точной фразе** и только после всех проверок.
4. **Не выдумывать данные.** Нет mint — показываем «не создан». Нет метаданных
   — не подставляем временный URL. Нет ключа RPC — это блокер, а не повод
   придумать ключ.
5. **Исторические документы не переписывать.** Они описывают прошлое; правка
   задним числом — подделка записи.
6. **Не обещать прибыль.** Сжигание уменьшает количество токенов — это факт из
   блокчейна, но не обещание цены. Beans нигде не называть токеном.
